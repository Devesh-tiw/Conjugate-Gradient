Regression is a linear system in disguise

Least squares fits Y = β₀ + β₁x by minimizing ‖A·w − b‖². Setting the gradient to zero gives M·w = v — a system with a magical property.

MODEL
ŷ = A·w,   A = [1 | x̃]

bias column of ones + standardized feature. w = (β₀, β₁).

NORMAL EQUATIONS
M = AᵀA,   v = Aᵀb

the ∇ = 0 condition of least squares.

SPD ✓
Mᵀ = M,   wᵀMw = ‖Aw‖² > 0

symmetric positive-definite — exactly what CG requires.

Why not just invert M?

Inversion costs O(n³) and destroys sparsity. Real systems — weather grids, FEM meshes, kernel matrices — have millions of unknowns. CG needs only M·d: one matrix-vector product per step, ~4 vectors of memory.

The price of admission

CG works on SPD systems. That is why we form M = AᵀA and standardize features — scaling shrinks the condition number κ(M), which directly controls convergence speed.

Five lines that never retrace a direction

Each search direction is M-conjugate to all previous ones (dᵢᵀM·dⱼ = 0). No step undoes earlier progress → exact solution in ≤ n steps. α comes from exact line search; β (Fletcher–Reeves) is the memory.

INIT
r₀ = v − M·w₀,  d₀ = r₀

residual = negative gradient = first direction

STEP SIZE
αk = rᵀr / dᵀMd

exact line search — closed form

WEIGHT UPDATE
xk+1 = xk + αkdk

move to the exact minimizer along dk

RESIDUAL UPDATE
rk+1 = rk − αkMdk

recycles M·d — no new matrix product

CONJUGATION β
βk = r′ᵀr′ / rᵀr

Fletcher–Reeves: memory of all past directions

NEW DIRECTION
dk+1 = r′ + βkdk

fresh gradient + conjugate memory — no zig-zag
